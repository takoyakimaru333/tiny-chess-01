A chess engine in 4 KB of Python: negamax alpha-beta with iterative deepening under a fixed node budget, quiescence search, a transposition table, and material + piece-square evaluation. Deterministic — no clock, no unseeded randomness — so a replay plays the same moves.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
